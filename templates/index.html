Fetch Games by Name or ID

Query by integer ID (`/api/games/1/`), URL slug (`/api/games/galaxy-drift/`), or exact title parameter (`?name=Valkyrie`). 

# 1. Fetch game details by ID:
curl -s http://127.0.0.1:8000/api/games/1/ \
  -H "Authorization: Token YOUR_ACCESS_TOKEN"

# 2. Fetch game details by slug or title:
curl -s http://127.0.0.1:8000/api/games/cyber-runner-2099/ \
  -H "Authorization: Token YOUR_ACCESS_TOKEN"

# 3. Search and filter by genre and platform:
curl -s "http://127.0.0.1:8000/api/games/?name=runner&platform=PC" \
  -H "Authorization: Token YOUR_ACCESS_TOKEN"
